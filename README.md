# Dice

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This is a script package for Miyu. It provides one tool, `dice`. It rolls dice written in dice notation and returns each die and the total.

| Parameter | Description |
|---|---|
| `dice` | Dice notation, default `1d6`. Join several terms with `+` and `-`; each term is `NdM` (`d%` means d100) or a constant. `NdM` can be followed by `khK`/`klK` (keep the highest/lowest K dice) or `dhK`/`dlK` (drop the highest/lowest K dice). Examples: `3d6+2`, `2d20kh1`, `4d6dl1` |
| `repeat` | How many times to roll the whole expression, 1–20, default 1 |
| `label` | What this roll is for; the tool returns it unchanged |

One roll can have at most 100 dice, each with 2–1000 sides. The random numbers come from the system entropy source (`secrets`). The tool uses only the standard library and needs no network access.
