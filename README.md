# 掷骰子

Miyu 脚本包，带一件工具 `dice`：照骰子写法掷骰子，交回每一颗和总数。

| 参数 | 说明 |
|---|---|
| `dice` | 骰子写法，默认 `1d6`。几项用 `+`、`-` 连起来：`NdM`（`d%` 是 d100）、常数；`NdM` 后面可以跟 `khK`/`klK`（留最高/最低 K 颗）、`dhK`/`dlK`（去掉最高/最低 K 颗）。例：`3d6+2`、`2d20kh1`、`4d6dl1` |
| `repeat` | 整个式子掷几次，1–20，默认 1 |
| `label` | 这一掷是为了什么，原样带回 |

一次至多 100 颗骰子，每颗 2–1000 面。随机数取自系统熵源（`secrets`）。只用标准库，不联网。
