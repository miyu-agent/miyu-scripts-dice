# 掷骰子

> <sub>本文档由 Anthropic 的 Claude Fable 5.2 生成。</sub>

这是 Miyu 的一个脚本软件包，提供一件工具 `dice`。它按照骰子记法掷骰子，返回每一颗的点数和总数。

| 参数 | 说明 |
|---|---|
| `dice` | 骰子记法，默认 `1d6`。多项之间用 `+`、`-` 连接，每一项可以是 `NdM`（`d%` 表示 d100）或者常数；`NdM` 后面可以加 `khK`/`klK`（保留最高/最低的 K 颗）、`dhK`/`dlK`（去掉最高/最低的 K 颗）。例如：`3d6+2`、`2d20kh1`、`4d6dl1` |
| `repeat` | 整个式子掷几次，1–20，默认 1 |
| `label` | 这一次掷骰的用途，工具会原样带回 |

一次最多掷 100 颗骰子，每颗 2–1000 面。随机数取自系统熵源（`secrets`）。工具只使用标准库，不需要联网。
